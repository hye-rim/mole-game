# 두더지 잡기 🔨

구멍에서 튀어나오는 두더지를 탭해서 잡는 반응속도 게임. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `game.js`)입니다.

- 3×3 구멍에서 두더지가 튀어나온다. 60초 동안 탭해서 잡는다 (칸 전체가 터치 영역)
- 보통 두더지 10점 · 🟡 금두더지 50점 + 2초 · ⛑️ 헬멧 두더지는 두 번 때려야 25점 · 💣 폭탄은 때리면 시간 -4초
- 연달아 잡으면 콤보가 쌓여 점수가 늘어난다(최대 +20). 두더지를 놓치거나 빈 구멍을 때리면 콤보가 끊긴다
- 시간이 갈수록 두더지가 빨리 숨고, 한꺼번에 최대 4마리까지 나온다. 폭탄은 6초부터, 헬멧은 18초부터, 금두더지는 10초부터 섞인다
- 600점 동메달 · 1200점 은메달 · 2000점 금메달. 최고 점수는 `moleBest`
- 조작: 탭 / PC는 마우스 클릭, 숫자 1~9(숫자패드 모양), P 일시정지, M 소리

규칙은 `logic.js`(화면 없이 Node 로 시험할 수 있다: `node test/logic.test.js`), 화면·입력·소리는 `game.js`.
